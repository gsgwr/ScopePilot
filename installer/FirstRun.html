ScopePilot 初回セットアップガイド

Windows on ARM（Snapdragonなど）はwin-arm64版、Intel/AMDのPCはwin-x64版を使用します。ARM64版は本体と.NETランタイムがARM64ネイティブです。外部ソフトの対応CPUは各配布元の案内を確認してください。

ScopePilot本体のインストールが完了しました。探索には以下の外部ソフトと接続設定が必要です。インストール完了だけではクローリングは開始されません。

更新前には案件を保存し、探索を終了してください。アンインストールしても案件データは残ります。外部サイトへの探索は、許可された対象と操作に限定してください。

1. 必要なソフトを準備する

ソフトと役割準備・確認
Node.js 24 LTS
Playwrightを実行する基盤		公式サイトからWindows版を導入。ScopePilotが使う場所は C:\Program Files\nodejs\node.exe です。
Microsoft Edge
探索用ブラウザー		Windowsに導入済みか確認します。Chromeだけでは代用できません。
Codex CLI
AIへの指示を実行するコマンドラインソフト		組織の承認済みWindows導入手順で設定してログインします。公式手順を参照。現在のScopePilotは %LOCALAPPDATA%\OpenAI\Codex\bin 配下の codex.exe を必要とします。npm版・WSL版だけでは接続設定できません。
Burp Suite Community Edition
通信を中継して記録するツール		公式手順でWindows版を導入。現在のScopePilotは %LOCALAPPDATA%\Programs\BurpSuite\jre\bin\java.exe を使用します。
Burp MCP Server拡張
CodexとBurpを接続する機能		BurpのExtensions → BApp Storeから MCP Server を導入します。

配布先に.NET SDK、Visual Studio、Git、GitHub CLIは不要です。外部ソフトの導入には、それぞれの管理者権限や組織の承認が必要になる場合があります。

2. Burpを起動する

  1. Community Editionで作業用のプロジェクトを開始します。
  2. Proxy Listenerを 127.0.0.1:8080 で有効化し、通常の巡回時はInterceptをOFFにします。
  3. MCPタブでサーバーを有効化します。接続先は http://127.0.0.1:9876 です。履歴参照などの承認設定は組織の手順に従ってください。

3. ScopePilotで接続を設定する

  1. スタートメニューからScopePilotを開き、「探索」の「環境チェック」を実行します。
  2. 不足している項目を解消して「MCP接続を設定」を実行します。MCPとはAIと外部ツールをつなぐ通信の仕組みです。
  3. Codexの実行中セッションがある場合は終了・再起動します。設定はユーザーのCodex設定に保存され、playwright・burpという名前の接続が更新されます。
ポータブル版から移行した場合も「MCP接続を設定」を押してください。0.11.2以降は古い配置先を検出し、新しいアプリフォルダーへ登録し直します。案件データのコピーは不要です。

4. 許可された研修サイトで確認する

新しい案件を作り、開始URLと許可Originを登録します。OriginはURLの「方式・ホスト・ポート」の組み合わせです。例：http://localhost:8082。研修サイトのポートはBurp Proxyの8080と分けてください。

少数ページで探索を実行し、通信が保存され、AI確認とBurp履歴の取得ができたことを確認します。「部分結果」や通信0件は、導入確認の合格を意味しません。画面の制約と実行ログを読んでください。

5. 困ったとき

  • ERR_PROXY_CONNECTION_FAILED：Burpの起動、Proxy Listenerの有効化、8080番ポートを確認します。
  • Codex・Node・Javaが見つからない：表に示す配置先を確認します。環境チェックがOKでもMCPの設定成功まで確認してください。
  • Transport closed・履歴取得タイムアウト：BurpのMCP有効化と承認状態、Codexの接続設定を確認します。再試行前にログと部分結果を保存してください。
  • セットアップが更新できない：探索を終了して案件を保存し、ScopePilotを閉じてから再実行します。

6. 更新・アンインストール

次版のSetup.exeを実行すると同じ場所へ更新します。Windowsの「設定」→「アプリ」→「インストールされているアプリ」から削除できます。案件と実行履歴は %LOCALAPPDATA%\ScopePilot に残り、Codex設定と外部ソフトも保持されます。案件を含むPC廃棄時のデータ削除は組織の手順に従ってください。

本インストーラーは未署名です。配布元と別添SHA-256を照合し、組織の実行ポリシーに従ってください。セキュリティ機能を無効化する必要はありません。
